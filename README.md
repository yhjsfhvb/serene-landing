# Serene — Luxury Beauty & Wellness Landing Page

A React + Vite + Tailwind CSS landing page for a luxury beauty/wellness brand.

## Features

- **Hero Section** — Full-screen background video with centered heading, subtext, and CTA
- **Quote Section** — Gradient background with parallax scroll animations (rainbow + clouds using requestAnimationFrame lerp)
- **Responsive Navbar** — Mobile hamburger menu with animated transitions (cubic-bezier easing)
- **Custom CSS** — Liquid glass effect, text glow, button glow

## Quick Preview

Open `preview.html` or `docs/index.html` directly in any browser — no build step required (uses CDN React + Tailwind).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS 3
- TypeScript 5

## Fonts

- Dancing Script — brand logo
- Instrument Serif — headings & quotes
- Inter — body text & buttons
